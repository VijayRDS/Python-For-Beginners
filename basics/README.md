# Basics

### 🧩 01_hello_world.py
Your first Python program — prints “Hello, World!” to the screen.  
**Concepts Covered:** Printing output, function definition, main block.


### 🧮 02_variables.py
Introduces Python variables and how they store data of different types.  
**Concepts Covered:**  
- Assigning and printing variables  
- Dynamic typing  
- Multiple assignments  
- Constants and conventions  
- Type checking using `type()`
